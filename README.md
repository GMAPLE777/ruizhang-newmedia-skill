# 村上春墅 · 新媒体运营 Skill

> 把村上春墅的品牌资料、平台打法、合规要求，装进 Claude。
> 你只要用大白话说需求，它就能给出**能直接拍、能直接剪**的内容包。
>
> **不需要懂代码，不需要懂 AI。**

---

## 一、30 秒了解：这是什么？

可以把它理解成 **给 Claude 的一本「村上春墅新媒体岗位手册」**。

- 平时它安静地放在那里，不占地方、不自动运行。
- 当你让 Claude 写村上春墅的脚本、想选题、看热点、检查合规时，它会自动翻开这本手册。
- 手册里写好了：品牌怎么说、哪些话不能说、抖音/视频号/小红书怎么区分、创始人 IP/招商/项目经理/销售各是什么语气。

### 它不是什么

- ❌ 不是一个需要安装的软件
- ❌ 不会自动帮你拍视频、剪视频、发视频
- ❌ 不会保证流量、不会保证爆款
- ❌ 不会替你做品牌决策

### 它能帮你做什么

| 场景 | 你可以这样说 |
|---|---|
| 看今天热点 | “看今天热点，给村上春墅出 3 个借势选题” |
| 写短视频脚本 | “写一条抖音防水视频，30 秒，要分镜和字幕” |
| 小红书图文 | “小红书发一篇余姚翻建审批避坑，自然带出品牌” |
| 创始人 IP | “我是创始人号，写一条‘为什么找标准化团队’，60 秒” |
| 招商内容 | “招商号，讲三免政策，目标留资，60 秒” |
| 项目经理/销售 | “我是项目经理，写条工地防水视频” |
| 改稿 | “这条脚本改成销售号语气，再接地气一点” |
| 合规检查 | “帮我检查这段文案有没有违规风险” |
| 矩阵排期 | “排下周矩阵发布计划，6 类账号各发几条” |

1. **Claude Code**（推荐桌面版，下载地址：https://claude.ai/code）

### 安装需要多久

大约 **3–5 分钟**。

## 四、安装方式 A：GitHub 插件安装（推荐）

> 适合：仓库管理员已经把你加进 GitHub 仓库，或者仓库是公开的。

### 第 1 步：确认你有仓库访问权限

让管理员把你加为仓库的 **Collaborator**（私有仓库必须这样做）。

### 第 2 步：打开 Claude Code

打开桌面版，或在一个项目文件夹里打开 Claude Code。

### 第 3 步：添加插件市场

在对话框输入（把 `<GitHub用户名>` 换成实际用户名）：

```text
/plugin marketplace add <GitHub用户名>/ruizhang-newmedia-skill
```

例如：

```text
/plugin marketplace add ruizhang-newmedia/ruizhang-newmedia-skill
```

按回车。第一次可能会让你登录 GitHub，按提示授权即可。

### 第 4 步：安装技能

```text
/plugin install ruizhang-newmedia-skill@ruizhang-skills
```

也可以输入 `/plugin`，在界面里：

1. 选择 **Browse and install plugins**
2. 找到 **ruizhang-skills**
3. 选择 **ruizhang-newmedia-skill**
4. 点击 **Install now**

### 第 5 步：新开一个会话

**重要：安装完必须新开会话或重启 Claude Code。**
技能是在会话启动时加载的，当前会话不会自动出现。

### 第 6 步：验证是否成功

新会话里输入：

```text
用 ruizhang-newmedia-skill 帮我写一条抖音视频，主题“农村建房为什么要图纸”，45 秒。
```

如果它开始输出“内容包 / 选题说明 / 口播脚本 / 分镜表 / SRT 字幕”，就说明安装成功。

### 安装失败怎么办

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 找不到 marketplace | 仓库名或用户名写错 | 检查 `用户名/仓库名` |
| 没有权限 / 404 | 私有仓库没加你 | 让管理员加 Collaborator |
| 安装后没反应 | 没新开会话 | 完全退出 Claude Code 再打开 |
| 公司网络失败 | GitHub 访问受限 | 改用“压缩包安装” |

## 八、提问万能公式

想让它一次写对，尽量带上这 6 个信息：

```text
平台 + 岗位 + 主题 + 时长 + 目标 + 素材/禁忌
```

例子：

```text
抖音 + 项目经理号 + 沿海自建房防水 + 30 秒 + 本地建房线索 +
素材有在建工地和完工样板房，不要出现电话号码和门牌。
```

**信息不全也没关系。** 它会先按默认值给一版可用初稿，并在开头写清楚它假设了什么。

默认值是：

- 平台：抖音
- 账号：企业品牌号
- 时长：30–45 秒
- 目标：按账号类型推断

## 九、它会给你什么

一条完整的视频需求，通常会输出 **7 个部分**：

1. **选题说明**：钩子类型、目标受众、核心痛点、预期动作
2. **标题与文案**：标题 ≤18 字、文案 ≤20 字、话题 ≤3 个
3. **口播脚本**：按秒分段，标注重音和停顿
4. **分镜表**：镜号、时间、画面、台词、字幕、音效/BGM
5. **SRT 字幕**：可直接导入剪映/ChatCut
6. **封面文案**：主标题、副标题、视觉建议
7. **合规自检**：通过项打勾，有风险的标 ⚠️ 并给替换建议

小红书图文会换成：标题、正文、话题、6–9 张配图建议、合规自检。

## 十、热点功能（可选）

> 需要电脑上安装 **Python 3.10 或更高版本**。
> 不会装也没关系，你可以手动把热点发给 Claude。

### 怎么用

在 Claude Code 里直接说：

```text
看今天热点，给村上春墅出 3 个借势选题。
```

它会运行抓取脚本，覆盖：

- 百度热搜 ✅
- 微博热搜 ✅
- 抖音热榜 ✅
- 微信公众号 ✅（第三方聚合，偶尔失败）
- 微信视频号 🟡（第三方聚合，偶尔失败）
- 小红书 ❌（没有稳定公开热榜）

### 手动运行

```powershell
python "<技能目录>/scripts/fetch_hot.py" --limit 5
```

只抓微博和抖音：

```powershell
python "<技能目录>/scripts/fetch_hot.py" --platform weibo,douyin --limit 10
```

### 小红书怎么办

小红书没有公开热榜，三种办法：

1. **手动**：你把小红书截图或链接发给我，我帮你提炼
2. **自建接口**：设置环境变量 `XHS_HOT_URL` 指向一个 JSON 接口
3. **付费数据**：RedFox / TikHub / SocialDataX 等（需要 Key）

### 抓不到怎么办

脚本会明确写“未获取 + 原因”，不会编造。你可以：

- 手动把热点贴给 Claude
- 直接做常青选题（避坑、工艺、案例、政策）

## 十二、常见问题（FAQ）

### 1. 我说了“写脚本”，但它没有用这个 skill？

两种办法：

- 明确点名：“用 **ruizhang-newmedia-skill** 帮我写……”
- 带上品牌词：“写一条**村上春墅**的抖音视频……”

如果还是不触发，输入 `/ruizhang-newmedia-skill` 直接调用。

### 2. 它能直接帮我剪映吗？

不能直接控制剪映。它可以输出**剪映能直接用的内容**：

- 分镜表
- SRT 字幕文件
- 口播稿
- 封面文案

后续如果公司接入剪映 MCP，才能自动生成草稿。

### 3. 它能自动找 B-roll 素材吗？

能规划“每个信息点需要什么画面”，但**素材必须你提供**（本地实拍或授权图库）。

它不会自动去抖音/小红书抓视频，也不建议这么做——版权和平台条款风险很高。

### 4. 它写的数据准确吗？

品牌数字只从 `references/品牌知识.md` 取（2000+ 户、98%、150000+ 客户等）。

如果某个数字手册里没有，它应该问你，而不是编造。**发布前仍要人工核对。**

### 5. 会不会泄露公司资料？

- Skill 只在本机运行，不会把 `references/` 上传到外部。
- 只有你主动把内容发给 Claude 时，内容才会进入对话。
- 热点抓取只读取公开榜单，不上传公司资料。
- **不要把内部资料放进公开仓库。**

### 6. 需要联网吗？

- 写脚本、选题、合规检查：需要 Claude 服务联网。
- 热点抓取：需要联网访问公开榜单。
- 图片素材：本地读取，不需要联网。

### 7. 同事都能用吗？

可以，但每个人都要：

1. 安装 Claude Code
2. 安装这个 skill（插件或压缩包）
3. 新开会话

私有仓库需要管理员给每个人加权限。

### 8. 手机能用吗？

Claude Code 主要在电脑上使用。手机端 Claude App 是否支持自定义 skill，取决于套餐和版本。

### 9. 我可以改里面的内容吗？

可以。改 `references/` 里的 Markdown 文件即可，改完重启会话生效。

但建议先备份，尤其是 `品牌知识.md` 和 `合规红线.md`。

### 10. 小红书热点为什么抓不到？

小红书没有公开热榜接口，网页需要登录，第三方接口大多要付费或已失效。**这不是脚本坏了。**

### 11. 提示 Python 不存在怎么办？

说明你还没装 Python。两个选择：

- 不装：热点功能手动喂，其他功能不受影响
- 安装：到 https://www.python.org/downloads/ 下载 3.10 以上版本，安装时勾选“Add Python to PATH”

### 12. 输出太长/太短怎么办？

直接说：

- “压缩到 30 秒，口播 150 字以内”
- “展开到 60 秒，多给两个分镜”
- “只要脚本，不要分镜和字幕”

## 十三、保密与使用范围（请务必阅读）

这个仓库包含**公司内部资料**，包括但不限于：

- 品牌手册与品牌数据
- 新媒体矩阵运营规划
- 账号管理制度与奖惩机制
- 招商加盟策略
- 品牌全案策划书（原文件标注“特级保密”）

### 建议

1. **GitHub 仓库设为 Private（私有）**，只给同事开权限。
2. 不要把仓库链接、压缩包转发到公司外部。
3. 对外发布内容时，遵守 `references/合规红线.md`：不出现电话号码、门牌、抽烟、小孩、喝酒等画面。
4. 不要把客户姓名、电话、合同、批文原件放进仓库。

### 如果你真的要“公开开源”

先做一次脱敏：

- 删除或改写 `references/全案策划书.md`（含组织架构、招商策略、保密等级）
- 删除 `references/合规红线.md` 中的奖惩金额
- 检查 `references/品牌知识.md` 中的合作品牌、创始人信息
- 确认品牌手册图片可以公开
- 再选择 MIT / Apache-2.0 等开源许可证

**没有脱敏就公开，可能造成商业信息泄露。**
