## 二、日常更新

### 改品牌事实、方法、合规

1. 直接编辑 `skills/ruizhang-newmedia-skill/references/*.md`
2. 本地试一条真实需求，确认输出正常
3. 提交 Git
4. 通知同事更新（插件更新或替换文件夹）

### 改完要不要重启

- 同事侧：更新后**新开会话**才生效。
- 维护者本地：同样新开会话。

### 版本号

修改 `marketplace.json` 里的 `metadata.version`，建议遵循：

- 修错别字/小补充：`1.0.1`
- 新增能力/新增文件：`1.1.0`
- 大改结构：`2.0.0`

## 三、热点脚本

```bash
python skills/ruizhang-newmedia-skill/scripts/fetch_hot.py --limit 5
```

需要 Python 3.10+。脚本只依赖标准库。

平台状态：

- 百度、微博、抖音：稳定
- 微信公众号：走 tophub + Jina，偶尔限流
- 微信视频号：同上，失败率更高
- 小红书：默认失败，需 `XHS_HOT_URL` 或手动提供

改脚本后至少跑一次：

```bash
python .../fetch_hot.py --platform baidu,weibo,douyin --limit 2
```

## 四、测试

如果保留 `evals/`，可以用 skill-creator 的流程跑对比测试。最低要求：

1. 抖音 30 秒脚本：检查 7 段结构、标题 ≤18 字、话题 ≤3、SRT 合法
2. 创始人 IP 60 秒：检查第一人称、3 个选题、品牌壁垒
3. 小红书图文：检查图文形态、搜索关键词、配图 6–9 张、品牌自然植入
4. 热点选题：检查来源、筛选理由、风险提示

## 八、常见维护问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 同事安装后不触发 | 没新开会话 | 重启 Claude Code |
| 插件市场找不到 | 仓库名错/私有仓库无权限 | 检查路径、加 Collaborator |
| 热点脚本 403 | 聚合站反爬 | 脚本会自动尝试 Jina；仍失败就手动喂 |
| 小红书抓不到 | 无公开接口 | 让用户手动提供或配 `XHS_HOT_URL` |
| 图片打不开 | 路径不对 | 确认 `assets/` 在 skill 目录下 |
