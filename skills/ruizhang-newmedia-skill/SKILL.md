# 村上春墅 · 新媒体运营工作流

## 这个 skill 解决什么

村上春墅的内容生产有固定套路：选准平台和账号 → 套住钩子 → 用品牌事实说话 → 输出可直接拍剪的内容包 → 发布前过合规。本 skill 把这条流水线固化下来，避免每次从零想、每次口径不一致。

**核心原则：品牌事实只从 `references/品牌知识.md` 取，方法只从 `references/内容方法论.md` 取，不凭记忆编数据、不套用其他品牌的打法。**

## 第一步：确认输入（最多问一轮）

开始写之前，先确定这四项。能从用户的话里推断的就推断，不要逐项盘问：

| 输入 | 取值 | 未指定时 |
|---|---|---|
| 平台 | 抖音 / 视频号 / 小红书 / 快手 | 默认抖音 |
| 账号类型 | 企业品牌号 / 创始人 IP / 招商加盟 / 设计师 / 项目经理 / 销售同城 | 默认企业品牌号；提到"加盟/招商/合伙人"→招商号；提到"我/老板/创始人"→创始人 IP |
| 内容目标 | 涨粉 / 建房线索 / 招商线索 / 品牌背书 | 按账号类型推断 |
| 形式与时长 | 视频口播 / 剧情 / 图文；15–35s / 30–60s / 60–90s | 流量款默认 30–45s |

把推断结果写在输出开头（"按抖音·企业品牌号处理"），用户看到不对会纠正。**不要为了确认而连续追问，先给可用的初稿。**

## 热点获取（用户问热点/热榜/找选题时先做）

运行本 skill 目录下的抓取脚本（skill 加载时系统会给出 base directory；以下 `<本 skill 目录>` 即该目录）：

```bash
python "<本 skill 目录>/scripts/fetch_hot.py" --limit 5
```

脚本覆盖：百度热搜、微博热搜、抖音热榜、微信视频号、微信公众号；小红书没有稳定公开源，通常返回失败，需用户手动提供截图/链接，或配置 `XHS_HOT_URL`。

拿到结果后读 `references/热点与选题.md`，对每条热点做四问筛选：**相关性、可借势、风险、时效**。输出 3–5 个借势选题，并明确列出"不建议使用的热点 + 原因"。

规则：热点只作为选题输入，事实以官方发布为准；不评论时政、不消费灾难、不传谣、不做医疗断言。某平台失败时如实写"未获取 + 原因"，不要编造。

## 工作流

### 1. 选题（用户要"想选题/不知道拍什么"时才做）

先读 `references/内容方法论.md` 的选题部分和 `references/平台与账号.md` 的内容板块。给 **5 个候选选题**，每个写清：

- 钩子类型（16 类里选 1 个）
- 目标受众（建房业主 / 加盟商 / 泛流量）
- 核心信息点（一句话）
- 建议时长

候选之间要有差异：不要 5 个都是"避坑"。至少覆盖 2 种内容板块（实景工艺 / 建房干货 / 招商 / 品牌格局 / 剧情）。

### 2. 写脚本

结构固定：**钩子（0–5s）→ 展开 → 价值输出 → 结尾引导**。

- 前 3 秒必须出现钩子；钩子从 `references/内容方法论.md` 的 16 类里选，并按平台调整（抖音要冲突/情绪，视频号要温和信任，小红书要搜索关键词）。
- 口播一句一个信息点，删口水话。中文口播按 **每秒 4–5 字** 估算：30s ≈ 120–150 字，60s ≈ 240–300 字（不含停顿）。
- 品牌锚点按需植入：宁波总部、三免·五大精工·八大交付、精心匠造恒久传承。**一条视频 1–2 个锚点即可，不要每句都堆。**
- 结尾温和引导（评论/私信/看主页），不做道德绑架式点赞。
- 涉及工艺时读 `references/工艺施工流程.md`，挑 1–2 个关键节点讲透，不背步骤。
- 需要风格参考时读 `references/文案样例库.md`，参考结构和语气，不逐字照搬。

### 3. 分镜表

把脚本拆成可拍的镜头：

- 30–60s 视频一般 6–12 个镜头，每镜 2–6 秒。
- 画面必须**可实际拍摄**：工地实拍、样板房、完工案例、材料特写、人物出镜、素材混剪。不要写"航拍全景+特效"这类成本过高的默认镜头，除非用户明确要。
- 竖屏 9:16；口播镜头与空镜/B-roll 交替，避免一镜到底。
- 标注字幕、音效、BGM 的位置。

### 4. 字幕 SRT

按口播稿生成标准 SRT：

```
1
00:00:00,000 --> 00:00:03,000
第一句字幕

2
00:00:03,200 --> 00:00:06,500
第二句字幕
```

规则：
- 序号连续，时间格式 `HH:MM:SS,mmm`，条目之间空一行。
- 每行 ≤15 个汉字，按语义断句，不要一句跨太多行。
- 时间按 4–5 字/秒估算，句间留 0.2–0.3s 间隙。
- 这是估算时间轴，交付时注明"时间轴为估算，导入剪映/ChatCut 后需微调"。

### 5. 发布包

- **视频标题 ≤18 字**：简短 + 关键词 + 留互动点，埋赛道关键词（余姚自建房、宁波乡墅等）。
- **视频文案 ≤20 字**：对内容做重点描述。
- **话题 ≤3 个**：1 个大热门 + 2 个垂直标签，不加无关话题。
- **封面文案**：主标题 ≤8 字，副标题 ≤10 字；封面与标题 2 选 1，风格统一（精工灰 + 暖金）。
- 平台适配：抖音重钩子，视频号重信任与转发，小红书标题带可搜索关键词、正文口语化。

### 6. 合规自检（每次交付前必做）

读 `references/合规红线.md`，逐条对照。最常踩的：

- 视频/直播不出现电话号码、公司门牌、抽烟、小孩、喝酒、赤身。
- 不说"风水""迷信"；不低俗、不引战、不骗赞。
- 不贬低同行、不承诺保底收益、不承诺审批必过、不夸大工期。
- "五年融资上市"只能表述为**品牌长期战略规划目标**，不作收益/上市承诺。
- 不搬运、不二次混剪抄袭；AI 生成内容建议标注。
- 极限词（最、第一、绝对）谨慎使用。

自检结果放在输出末尾：通过的打勾，有风险的标 ⚠️ 并给出替换建议。

```markdown
# 小红书笔记｜{主题}
```

## 平台速查

| 平台 | 内容逻辑 | 写法 |
|---|---|---|
| 抖音 | 算法推荐，完播+互动定生死 | 前 3 秒强钩子；15–45s 为主；重冲突、痛点、结果 |
| 视频号 | 社交推荐，转发到群 | 30s–3min；温和、信任、利于私域；少用强冲突 |
| 小红书 | 搜索 + 种草，长尾 | 标题带关键词；真实人设；图文为主；避免硬广 |
| 快手 | 下沉乡镇流量 | 真实、接地气；选择性轻运营 |

## 账号类型速查

| 类型 | 目标 | 语气与落点 |
|---|---|---|
| 企业品牌号 | 品牌信任、背书、泛咨询 | 稳重、体系化；讲实力、工艺、交付、案例 |
| 创始人 IP | 人格信任、筛高价值伙伴 | 第一人称、真实故事、有观点；讲赛道、战略、长期主义 |
| 招商加盟号 | 加盟表单、考察邀约 | 利益 + 机会 + 案例 + 数据；讲扶持、盈利、可复制 |
| 设计师号 | 设计美学、专业背书 | 作品、户型、审美；讲图纸到落地 |
| 项目经理号 | 工地真实、打消怕翻车 | 第一视角、手持实拍；讲工艺、验收、节点 |
| 销售同城号 | 本区县线索 | 接地气、本地化；讲政策、案例、预约看房 |

## 事实核验与主动检索（强制）

**第一条：不编造。** 任何数字、政策、案例、客户、奖项、价格、工期、审批结果、竞品信息，没有出处就不要写。写不出就明确说"资料里没有"，不要用"据说/网上说/一般来说"糊过去。

**来源分级**：
1. **品牌事实**：只从 `references/品牌知识.md` 取。版本冲突未定稿时，用默认口径并提示"待公司定稿"。
2. **政策法规/审批**：查官方来源（政府官网、住建/自然资源部门公告、乡镇窗口），至少两个来源交叉核对；标注来源、发布日期、链接。
3. **行业数据**：优先官方统计/协会/权威媒体；标注日期，过时数据不用。
4. **热点**：用 `scripts/fetch_hot.py` 或用户提供的截图/链接；热点只作选题输入，事实以官方发布为准。
5. **不可用来源**：自媒体传言、无署名截图、竞品软文、未标注出处的 AI 生成内容。

**缺信息时的动作**：
- 先查 `references/`；
- 仍然没有，且用户需要事实性内容 → 主动联网检索（WebSearch/WebFetch），优先官方网站；
- 检索不到，或没有联网/工具权限 → 明确说明限制，请用户提供资料；
- 绝不猜。

**引用格式**：
`来源：<机构/网站>《<标题>》，<发布日期>，<链接>`
无法核实的标注 `🟡 待核实`；确认没有的标注 `❌ 资料中没有`。

**禁止**：
- 把网络内容当作品牌事实；
- 用旧政策冒充现行政策；
- 用 AI 生成画面冒充真实工地/客户案例；
- 为了让文案"更有说服力"而补数字、编案例。

**交付时**：在合规自检里增加"事实核验"一行：哪些已核实、哪些待核实、哪些没有资料。

图片按 `references/图片素材索引.md` 的路径读取；864×576 的手册页仅作参考，不进成片。

## 交付前质量清单

- [ ] 前 3 秒有明确钩子，且钩子类型说得出来
- [ ] 口播字数与目标时长匹配（4–5 字/秒）
- [ ] 分镜可实际拍摄，没有不可执行的镜头
- [ ] 标题 ≤18 字、文案 ≤20 字、话题 ≤3 个
- [ ] SRT 格式正确、时间轴连续
- [ ] 品牌锚点 1–2 个，没有堆砌
- [ ] 数字全部有出处
- [ ] 政策/案例/竞品信息已核验；不确定处标 🟡 或 ❌，没有编造
- [ ] 合规红线逐条过，风险项已标注
- [ ] 平台与账号语气一致（抖音/视频号/小红书不混用）
- [ ] 若用了热点：来源已记录、未评论时政/消费灾难、事实以官方为准

## 后续扩展

- 热点获取：已提供 `scripts/fetch_hot.py`（百度/微博/抖音/视频号/公众号）；小红书需 `XHS_HOT_URL` 或手动提供，后续可接 MCP/付费数据源。
- 剪辑：内容包可直接导入剪映；ChatCut 可通过其 MCP 插件接收脚本/字幕进一步自动剪辑。
- 知识更新：维护者直接修改 `references/` 后提交仓库；同事更新用 `/plugin update` 或重新拉取。
