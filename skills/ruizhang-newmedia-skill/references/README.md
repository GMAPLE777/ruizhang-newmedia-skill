## 读取优先级（脚本写作场景）

1. **强制**：`合规红线.md`（红线）
2. **必读**：`品牌知识.md`（品牌事实）+ `内容方法论.md`（方法）+ `事实核验与检索.md`（不得编造）
3. **按需**：`平台与账号.md`（看平台/账号类型）、`工艺施工流程.md`（看工艺）、`文案样例库.md`（看风格）、`热点与选题.md`（做热点选题时）
4. **背景**：`全案策划书.md`（招商/战略/组织类长内容）

## 重要提醒

`品牌知识.md` 文末有「⚠️ 版本冲突待确认」——Slogan、五大精工第 5 项、八大交付、品牌定位在不同文档表述不一致，**写内容前需先定稿以哪版为准**。
