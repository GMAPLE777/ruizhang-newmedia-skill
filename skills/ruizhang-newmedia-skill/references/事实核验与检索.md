# 村上春墅 · 事实核验与主动检索

> 目标：**不编造、可追溯、该查就查**。
> 任何数字、政策、案例、客户、奖项、价格、工期、审批结果、竞品信息，没有出处就不要写。

---

## 一、来源分级

| 级别 | 来源 | 用法 |
|---|---|---|
| A 品牌事实 | `references/品牌知识.md`、公司正式文件 | 只能从这里取品牌数据与口径 |
| B 政策法规 | 政府官网、住建/自然资源部门公告、乡镇（街道）窗口 | 必须交叉核对，标注发布日期 |
| C 行业数据 | 官方统计、行业协会、权威媒体 | 标注日期，过时数据不用 |
| D 热点 | `scripts/fetch_hot.py`、用户提供的截图/链接 | 只作选题输入，事实以官方发布为准 |
| E 不可用 | 自媒体传言、无署名截图、竞品软文、未标注出处的 AI 内容 | 不作为事实依据 |

## 二、缺信息时的动作顺序

1. **先查本地**：`references/` 里有没有？
2. **再问用户**：能不能提供官方文件、合同、批文、数据？
3. **主动检索**：需要事实性内容时，用 WebSearch / WebFetch 查官方来源。
4. **交叉验证**：政策、补贴、审批、造价等关键信息，至少两个来源一致。
5. **仍然没有**：明确写“资料中没有/无法核实”，给用户选项，**绝不猜**。

## 三、引用格式

```text
来源：<机构/网站>《<标题>》，<发布日期>，<链接>
```

输出时用三种标记：

- ✅ 已核实：有明确来源
- 🟡 待核实：有线索但未确认，或来源不够权威
- ❌ 资料中没有：本地和公开检索都没有

## 四、必须核实的常见项

| 类型 | 例子 | 核实方式 |
|---|---|---|
| 政策/审批 | 余姚翻建面积、层数、公示天数 | 余姚/宁波政府官网、乡镇窗口 |
| 补贴 | 农村建房补贴、适老化改造补贴 | 政府公告，注意年度和地区 |
| 造价/工期 | “多少钱一平”“几个月交付” | 公司报价文件；不承诺具体工期 |
| 质保 | 主体终身质保的具体条款 | 合同/公司正式口径 |
| 合作品牌 | 某品牌是否授权合作 | 公司供应链/授权文件 |
| 加盟政策 | 三免、扶持包、区域保护 | 公司招商正式文件 |
| 经营数据 | 2000+ 户、98%、150000+ | `references/品牌知识.md` |
| 竞品信息 | 同行价格、工艺、规模 | 不主动评价；确需引用须有公开来源 |

## 五、禁止事项

1. 编造数字、政策、案例、客户、奖项、价格、工期、审批结果。
2. 把“据说”“网上说”“一般来说”当作事实。
3. 用旧政策冒充现行政策。
4. 用 AI 生成画面冒充真实工地、真实业主、真实交付。
5. 为了让文案更有说服力而补数字、编故事。
6. 把网络内容直接当作品牌事实。

## 六、检索工具与限制

- **WebSearch**：适合找线索，对中文平台覆盖有限；结果必须回到原始来源核对。
- **WebFetch**：适合抓公开页面；登录墙、反爬、跨域跳转可能失败。
- **fetch_hot.py**：只抓公开热榜；失败时如实报告。
- 没有联网或没有工具权限时：明确说明“我无法核实”，请用户提供资料，不要用记忆硬答。

## 七、交付时的“事实核验”一行

在合规自检里增加：

```markdown
### 事实核验
- ✅ 已核实：2000+ 户、98% 满意度（来源：品牌知识.md）
- 🟡 待核实：余姚某镇面积分档（建议发布前向窗口确认）
- ❌ 资料中没有：2026 年最新补贴金额（未检索到官方公告，暂不写）
```
