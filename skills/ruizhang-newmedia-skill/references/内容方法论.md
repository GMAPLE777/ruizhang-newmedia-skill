# 村上春墅 · 内容创作方法论

> 写脚本、拍剪、发布时遵循的核心方法。此文件未来将沉淀为 skill 的正文指令。

---

## 一、核心逻辑

抖音算法优先看**完播率、点赞、评论、收藏、转发**。
优质视频 = 清晰垂直定位 + 强钩子开头 + 有价值内容 + 干净的视听质感 + 合规原创。

账号给用户的价值四选一：**学到东西 / 解压开心 / 引发共鸣 / 避坑省钱**。

**账号定位三件事**（先定这个再写脚本）：
1. **垂直定位**：基于农村自建房、乡村别墅建造装饰一站式服务创作，不什么都发；账号标签越清晰，推流越精准
2. **明确价值**：给用户学到东西 / 解压开心 / 引发共鸣 / 避坑省钱
3. **建立人设**：固定出镜人、统一风格、口头禅，方便用户记住

## 二、万能脚本结构

**钩子（0–5s）→ 展开内容 → 价值输出 → 结尾引导**

- 钩子是生命线，前 3 秒定生死
- 中间内容：一句一个信息点，删掉口水话；口播干货常用公式「现象 → 危害 → 原因 → 解决方案」
- 结尾：给总结金句 + 温和引导评论（不道德绑架点赞），如"你踩过这个坑吗？评论区说说"
- 时长建议：新手优先 **15–45 秒**（易拉高完播）；深度干货 1–3 分钟，不冗长拖沓

## 三、钩子库（16 类，原理 + 公式 + 示例）

> 详细完整版见原文《短视频钩子参考资料.txt》。以下为核心分类与常用公式。

| 类型 | 原理 | 公式 / 示例 |
|---|---|---|
| 1 好奇类 | 悬念勾起探索欲 | "为什么能力没你强的朋友混得比你好？" |
| 2 挑战类 | 把不可能变有趣 | 奇葩/盲盒/打卡/互动挑战 |
| 3 揭秘类 | 窥探真相 | "xxx 才知道的秘密""揭秘 xxx 可能会得罪同行" |
| 4 避坑类 | 趋利避害 | "新手做短视频一定会踩的几个大坑" |
| 5 盘点类 | 信息集合 | "5 个你不知道的减肥冷知识" |
| 6 借势类 | 蹭热点/权威/名人 | 借权威机构、古籍、名人、大众选择、网红热点 |
| 7 痛点类 | 直戳困扰 | "腿粗夏天不敢穿裙子怎么办" |
| 8 恐惧类 | 放大焦虑 | "90% 得胃炎的人都有这两个坏习惯" |
| 9 利益输送类 | 给干货福利 | "打开这两个开关，流量直接翻倍" |
| 10 简单速成类 | 快速学会 | "两招快速改善体态" |
| 11 极限式 | 极限词抓眼球（注意合规） | "99% 人都不知道的旅游秘密" |
| 12 数字类 | 数字具象有说服力 | "4 步告别脱妆卡粉" |
| 13 反差/争议类 | 打破认知 | "摸鱼的人反而更容易成功" |
| 14 对比式 | 前后/两者差距 | "月薪 3000 和 3w 文案差别在哪" |
| 15 互动类 | 对话观众拉互动 | "听劝第 X 天，评论区告诉我下一步" |
| 16 同理心类 | 共情共鸣 | "人生第一次摆地摊，希望大家多多支持" |

**行业适配钩子（乡墅赛道专用）**：
- 痛点提问："为什么农村自建房施工不规范？"
- 反差冲突："包工头不给图纸、不签合同都是智商税"
- 结果前置："掌握这 3 个技巧，让你农村建房不踩坑"
- 悬念好奇："我做乡墅建造 3 年多，才发现这个秘密"

## 四、拍摄规范

- 比例 9:16 竖屏，1080P，30 帧，开高清，擦干净镜头
- 光线优先自然光，人脸正面打亮，避免逆光黑脸
- 环境安静，**收音＞画质**，建议领夹麦，杂音大直接废掉
- 构图三分，主体居中；多切镜头，不一镜到底；运镜平稳少乱晃
- 原则：原创实拍优先，禁止搬运、二次混剪抄袭；AI 生成内容建议标注

## 五、剪辑规范

- 粗剪删停顿、重复、废镜头，节奏紧凑
- 字幕：自动字幕 + 手动改错，字号适中（约主题字体一半）+ 描边，口播类必配
- 音频：配乐音量 5%–15%，低于原声；选同赛道热门 BGM，不盖人声
- 转场：叠化、硬切即可，不堆花哨特效
- 封面：统一风格，大字突出主题，高清干净（封面决定点击率），标题与封面契合

## 六、发布细节

- 字幕标题 ≤18 字：简短 + 关键词 + 留互动点，埋赛道关键词
- 主题/文案：≤20 字，可只设一个
- 话题：≤3 个精准标签（1 大热门 + 2 垂直小标签），不加无关话题
- 发布时间：看创作者中心「粉丝活跃时段」；开启高清发布；按需定位（工地/公司所在）
- 发布后半小时：及时回复前排评论并点赞，引导讨论

## 七、复盘迭代

- 看前 3 秒大量划走 = 钩子不行；中段掉人 = 内容枯燥；结尾掉人 = 没价值
- 优先看**完播率、5 秒留存、收藏率**，不只盯着点赞
- 持续模仿爆款结构，但内容、观点、画面做差异化，不照搬

## 八、选题思路（缺选题时按此找）

1. 用户价值四选一：新闻资讯、知识分享、趣味看点、行业痛点
2. 蹭抖音每日热榜
3. 同行业优质号内容参考（不照搬）
4. 创作者中心「创作灵感」
5. 评论区痛点
6. 题材风格：趣味剧情、开工/上梁/乔迁祝福顺口溜、行业歌曲诗词、VLOG、空镜+BGM、行业术语诠释、企业文化团建、工程现场情景剧、建造历史典故、案例探访

## 九、关键词库（创作者中心搜抖音指数）

农村自建房、乡村别墅、乡墅、一站式服务、包工包料、村上春墅、别墅建造、自建房装修、盖房子、室内装修、家装、别墅装饰、硬装、全案式家装、装修效果图 + 地域名（宁波、余姚、慈溪、镇海、江北、鄞州、北仑、奉化、象山、宁海）

## 十一、红线避坑（详见《合规红线.md》）

- 视频/直播不出现电话号码、公司门牌、抽烟、小孩、喝酒
- 不低俗、引战、诱导互骂、骗赞骗评论
- 口播/直播尽量不说"风水""迷信"词汇
- 不直接搬运爆款视频
